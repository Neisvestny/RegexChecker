Регулярные выражения предоставляют краткий способ описания шаблона, используемый для проверки, поиска, сопоставления, замены или разделения содержимого строки.
Требуется создать «помощник» (инструмент) для проверки выражений, используемых в приложениях, для проверки на регулярность

Необходимые требования:
[] Пользователь вводит произвольное выражение (не обязательно регулярное).
[] Пользователь вводит произвольную строку (регулярное выражение не обязательно содержится).
[] При нажатии соответствующей кнопки осуществляется проверка на регулярность.
[] В случае, если введено не регулярное выражение, выдать предупреждающее сообщение.
[] В случае, если введена пустая строка, выдать предупреждающее сообщение.
[] В случае, если регулярное выражение содержится в строке (тексте) – выделить его, в противном случае выдать сообщение об его отсутствии.

!!! Избегать использования regex
